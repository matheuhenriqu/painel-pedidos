# Regras de Desenvolvimento do Projeto

## Git & GitHub
- **Sempre subir as alterações para o GitHub**: Ao concluir qualquer alteração de código, melhoria ou correção, deve-se obrigatoriamente fazer o commit e o `git push origin main` para manter o repositório remoto sempre sincronizado.
- As mensagens de commit devem seguir o padrão semântico (Conventional Commits) em português (ex.: `feat: ...`, `fix: ...`, `style: ...`).
